# UNO Pickleball Philippines — GitHub / Vercel

This is a fresh GitHub-ready website set for UNO Pickleball Philippines.

## Upload to GitHub
1. Create/open the GitHub repository connected to Vercel.
2. Upload **everything inside this folder** (including the `assets` folder).
3. Commit the changes.
4. Vercel will automatically deploy the new commit.
